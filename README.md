# 投资 X Buddy

面向投资研究者的证据工作台。输入研究目标和沪深股票代码后，系统形成计划，要求用户批准只读取证，调用公开行情并展示来源、时间、单位、两源核验、计算结果和证据缺口。线程、检查点与用户主动保存的记忆保存在浏览器本地。

## 运行

需要 Node.js 22 或以上版本。

```bash
npm install
npm start
```

打开 `http://127.0.0.1:8714/`。可通过 `BUDDY_PORT` 指定端口。代理网络环境使用 Node.js 支持的 `--use-env-proxy`。

## 研究流程与取舍

工作台围绕近两个交易日的未复权行情构建真实闭环：目标与标的、计划审批、数据读取、证据比对、结果与导出。工具登记在 `/api/tools`，金融数据只读；每个线程有调用次数上限、超时、停止按钮、运行记录和检查点。刷新后，执行中的任务回到暂停状态，继续执行时保留已完成步骤。已保存的研究摘要可以作为本机长期记忆回查，原始证据保留在对应线程。

证据展示股票代码、指标、原始字段、数值、单位、交易日、抓取时间、未复权口径和数据源链接。两来源同日收盘价不一致时保留冲突并停止对应比较；单一来源或日期缺失时明确提示。差额和变化率在浏览器中按证据确定性计算，财报、估值和因果判断不在当前行情证据范围内。

## 数据与模型

公开行情来自东方财富和腾讯证券，接口返回及抓取时间以实际调用为准。数据源可能变更、限流、暂不可用或因停牌和节假日不更新；请求失败、证据缺失和来源冲突会在界面报告。扶摇和 iFinD 本次未配置访问密钥，未将其他来源标为这两项数据。

服务端支持按需配置 OpenAI 兼容接口：`BUDDY_LLM_URL` 为完整的 HTTPS chat completions 地址，`BUDDY_LLM_MODEL` 为模型名，`BUDDY_LLM_KEY` 为密钥。只在服务端设置，勿提交仓库。模型用于计划标题；系统将公开代码与受限主题类别发送给配置的服务，不发送原始研究目标。无模型或调用失败时明确使用规则计划，界面不声称已调用大模型。详情与实际验证状态见 [AI 使用与验证记录](AI-AND-TESTS.md)。

## 使用边界

产品只支持历史行情与证据研究，不提供直接买卖指令、确定性预测或收益承诺。切勿输入真实持仓、身份或其他敏感信息。本机浏览器存储不支持跨设备同步。产物中的缺失数据必须继续查证，无法仅凭股价变化推断盈利或其他基本面原因。

## 当前限制

数据覆盖常见沪深 A 股代码前缀，具体允许范围以接口校验为准；当前只覆盖近两个有效交易日的日线。尚未接入财务报表、公告原文、投资组合、自动跟踪通知或跨设备持久化。规则规划不能替代通用模型推理；需要模型的能力取决于实际配置与可用性。代码使用 AI 协作编写，具体经过和真实验证结果见记录。
